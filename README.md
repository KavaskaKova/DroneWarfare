# DroneWarfare

**DroneWarfare** — это игровой режим для Garry's Mod, посвящённый боевым беспилотникам, уничтожению целей и развитию собственного арсенала.

Приобретай различные боевые дроны, уничтожай вражескую технику и NPC, зарабатывай деньги и постепенно открывай доступ к более мощным беспилотным аппаратам.

Твоя задача — эффективно использовать дроны, зарабатывать на уничтожении целей и стать настоящим мастером беспилотной войны!

## 🎮 Основные возможности
- 🚁 **Магазин дронов** — покупка различных боевых беспилотников за внутриигровую валюту. (Q-Menu)
- 🎯 **Система наград** — получение денег за уничтожение NPC, автомобилей, грузовиков и танков.
- 💾 **Сохранение денег** — баланс сохраняется между респавнами и подключениями к серверу.
- 📊 **HUD** — отображение текущего баланса прямо во время игры.

## 🚁 Покупка дронов

В режиме предусмотрен отдельный магазин боевых беспилотников.
- Покупка осуществляется за внутриигровые деньги.
- При покупке дрон появляется перед игроком или в точке прицеливания.

## 📦 Установка

1. Скачайте репозиторий.
2. Создайте папку `dronewarfare` в директорию:

   `garrysmod/addons/`

3. Перенесите файлы с репозитория в папку `dronewarfare`
4. Скачайте контент для режима игры (пока не доступен)
5. Выберите игровой режим в главном меню **DroneWarfare**.
6. зайдите на любую карту **dw_**
